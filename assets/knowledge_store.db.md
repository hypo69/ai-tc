

Файл **`knowledge_store.db`** (расположенный в служебной директории `.workspace/` воркспейса `דוד_משה`) представляет собой **локальную реляционную базу данных SQLite структурированных знаний, версий документов, графа связей и телеметрии** этого рабочего пространства в модуле `apps.ai_assistant` (AI Windows Admin).

---

### 1. Что хранится в этой базе данных

База построена по модульной схеме (ТЗ раздел 7) и содержит следующие таблицы и данные:

| Таблица / Слой | Что хранится | Текущее состояние для воркспейса `דוד_משה` |
|---|---|---|
| **`documents`** | Реестр проиндексированных документов, хеши (`content_hash`), относительные и полные UNC-пути, язык (`he` — иврит), текущая версия, статус и внешний ID в Paperless-ngx (`paperless_id`). | 3 документа: транскрипт звонка `02_transcript_david_moshe_shmulik_v3.md`, `דוד משה.txt` и документ из Paperless (`paperless://17`, ID=17). |
| **`document_versions`** | Полные слепки содержимого документов (`raw_content`) с привязкой к номерам версий и коммитам Git (`commit_hash`). | Тексты транскриптов звонка между Давидом Моше и Шмуликом (покупка коровы «Зина»). |
| **`document_chunks`** | Разбивка документов на фрагменты/предложения с границами символов (`char_start`, `char_end`) для семантического поиска и RAG. | Сформированные чанки на иврите. |
| **`entities`** & **`facts`** | Извлеченные именованные сущности (персоны, локации, объекты) и факты вида «субъект–предикат–объект / отношение обладания» с оценкой достоверности (`confidence`). | Факты о ферме Давида Моше, характеристиках коров (Зина, Дина, Рина), надоях молока (8.3 л/день) и т.д. |
| **`fact_relations`** & **`fact_sources`** | Связи между фактами и цитаты-источники из текста (с привязкой к конкретному смещению символов). | Подтверждающие цитаты из диалогов. |
| **`temporal_evidence_links`** | Темпоральный граф знаний (`TemporalCodeGraph` / `EvidenceLink`): ребра с окнами валидности (`valid_from`, `valid_to`), статусами `ACTIVE` / `SUPERSEDED` и привязкой к Git-коммитам. | 34 темпоральные связи между коммитами, документами и извлеченными фактами. |
| **`language_analysis`** | Полные результаты лингвистического и морфологического анализа (`analysis_json`). | Результаты анализатора `HebrewSemanticMorphoAnalyzer`. |
| **`embedding_registry`** | Реестр векторных индексов FAISS для семантического поиска. | Индекс `TextRAG-FAISS-256` (размерность 256, 84 вектора, файл `ws_דוד_משה.faiss`). |
| **`analysis_runs`** & **`model_usage`** | Журнал запусков анализаторов, время выполнения (latency), факты, статистика потребления моделей. | Метрики анализа документов (длительность от 1.3 мс до 408 мс). |
| **`query_history`** & **`app_settings`** | История поисковых запросов пользователей и локальные настройки рабочей области. | Хранилище диалогов и параметров. |

### 2. С чем взаимодействует эта база

1. **`KnowledgeStore` (`apps/ai_assistant/core/knowledge_store.py`)**:
   - Главный фасад доступа к данным через репозитории `WorkspaceRepoMixin`, `DocumentFactRepoMixin`, `TelemetryRepoMixin`.
2. **`TemporalCodeGraph` (`apps/ai_assistant/core/temporal_code_graph.py`)**:
   - Управляет таблицей `temporal_evidence_links`, связывает сущности и факты с изменениями в Git-ревизиях рабочего пространства.
3. **Модуль RAG и векторного поиска (`apps/ai_assistant/core/rag/`)**:
   - Использует `embedding_registry` и координаты чанков для контекстной выборки ответов на вопросы пользователя.
4. **Лингвистические анализаторы (`HebrewSemanticMorphoAnalyzer` / `DocAnalyzer`)**:
   - Записывают разобранные предложения, леммы, токены и извлеченные факты в `language_analysis`, `entities` и `facts`.
5. **Интеграция с Paperless-ngx (`paperless_connector.py`)**:
   - Связывает локальные документы с загруженными в Paperless сканами/документами (в данном воркспейсе — документ `paperless://17`, акт проверки перевозки скота).
6. **Сценарий `david_moshe_telegram` (`apps/ai_assistant/config.json`)**:
   - Автоматическая цепочка обработки: транскрибирование аудиозвонка (`דוד משה - שמוליк שיחת טלפון.mp3`) $\rightarrow$ версионирование в Git $\rightarrow$ извлечение фактов $\rightarrow$ сохранение в `knowledge_store.db`.
7. **REST API & WebGUI (`apps/ai_assistant/api/routers/`)**:
   - Эндпоинты панелей аналитики, графа знаний, документов и семантического поиска обращаются к этой базе для отображения данных в веб-интерфейсе.

### 3. Примечание по путям (`app\data` vs `data`)

- **Основная рабочая база воркспейса** расположена по пути:
  `data\workspaces\דוד_משה\.workspace\knowledge_store.db` (~360 КБ, содержит все 14 таблиц, 3 документа, факты, эмбеддинги и темпоральные связи).
- Файл по пути **`app\data\workspaces\דוד_משה\.workspace\knowledge_store.db`** (24 КБ) — это временная/дублирующая база, созданная при вызове `TemporalCodeGraph` через относительный путь `app/data/...`, где инициализирована только таблица `temporal_evidence_links`. Основные рабочие данные системы находятся в `data\workspaces\דוד_משה\.workspace\knowledge_store.db`.

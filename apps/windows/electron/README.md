# Оболочка Electron для ai-tc (Десктопный клиент)

## Описание
Десктопная клиентская оболочка на базе Chromium + Node.js (Electron runtime) для веб-интерфейса и диагностической системы **ai-tc** (Test Computer).

## Возможности
- Интеграция с локальным сервером FastAPI и открытие веб-интерфейса `/tc`.
- Нативная иконка приложения и системного трея: **красная дрель** (`red_drill.png` / `red_drill.ico`).
- Развертывание окна на весь экран (100% maximized) при запуске.
- Системный трей Windows с возможностью сворачивания и восстановления окна.
- Нативное меню (Файл, Правка, Вид, Инструменты, DevTools).
- Изоляция пользовательских данных и кэша в директории `data/chromium/`.

## Запуск
Запуск осуществляется автоматически через сценарий запуска:
```powershell
.\tc.ps1               # Запуск в режиме Electron (по умолчанию)
.\tc.ps1 -Engine electron
```
Либо напрямую через CLI:
```powershell
py main.py --engine electron
```

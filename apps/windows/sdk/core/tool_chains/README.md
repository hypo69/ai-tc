# Цепочки инструментов (`apps.windows.sdk.core.tool_chains`)

Планирование и пошаговый запуск цепочек диагностических/административных инструментов.

| Файл | Назначение |
|---|---|
| `catalog.py` | Шаблоны типовых цепочек |
| `planner.py` | Семантический подбор цепочки под запрос |
| `engine.py` | Исполнение шагов агентом |
| `models.py` | Модели цепочек, шагов, доказательств |
| `storage.py` | SQLite: определения, запуски, шаги, доказательства |
| `router.py` | FastAPI-роутер планирования и запуска |
| `tests/` | `test_tool_chains.py` |

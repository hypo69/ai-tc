# Лончеры телеметрии

| Скрипт | Назначение |
|---|---|
| `Install-TelemetryExe.ps1` | Сборка `AITelemetry.exe`, установка Windows Service; флаги `-Status`, `-Start`, `-Stop`, `-Restart`, `-Uninstall` |
| `Install-TelemetryTask.ps1` | Установка и управление задачей планировщика сбора телеметрии |
| `Run-Telemetry.ps1` | Запуск и управление службой |
| `Show-StartLog.ps1` | Стартовый лог, конфигурация, статус БД и ошибки |

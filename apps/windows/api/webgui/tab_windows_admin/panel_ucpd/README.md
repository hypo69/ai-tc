# Панель управления драйвером User Choice Protection Driver (UCPD)

**Updated:** 2026-11-01 14:40:00

## 📋 Описание панели

Суб-панель вкладки `tab_windows_admin` (`#tab-windows-admin#ucpd`) для комплексного аудита и безопасного управления драйвером **UCPD** (User Choice Protection Driver) и связанной фоновой задачей планировщика **UcpdVelocity** в Windows 11.

---

## 🛡️ Ключевые возможности

1. **Восстановление исходной конфигурации**:
   При включении восстанавливается именно исходный сохраненный режим запуска драйвера (`start=system` / код 1 или `start=auto` / код 2), предотвращая искажение заводских настроек ОС.
2. **Согласованность состояния**:
   Раздельный учет и отображение:
   - Режима запуска драйвера в реестре (`SYSTEM_START`, `AUTO_START`, `DISABLED`).
   - Фактического выполнения драйвера в ядре (Running / Stopped) и высоты в `fltmc` (`385250.5`).
   - Состояния задачи планировщика `\Microsoft\Windows\AppxDeploymentClient\UCPD velocity` (`Ready`, `Disabled`).
   - Требования перезагрузки системы (`reboot_required`), если драйвер еще находится в памяти ядра.
3. **Безопасность**:
   Обязательное предупреждение о снижении системной защиты пользовательских предпочтений и ассоциаций браузера перед деактивацией.
4. **Обработка частичных сбоев**:
   При успешном изменении службы и ошибке изменения задачи планировщика API возвращает частичный результат (`partial_success`) с подробными предупреждениями.
5. **Экспериментальное тестирование связи с TaskbarDa**:
   Эмпирическая проверка поведения реестра на текущей сборке Windows 11 без ложных предположений о блокировке.
6. **Аудит дрейфа после Windows Update**:
   Мониторинг несанкционированного повторного включения драйвера после обновлений ОС.

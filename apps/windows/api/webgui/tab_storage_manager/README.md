# Вкладка `tab_storage_manager` — Диски и тома

Физические диски, тома, клонирование и бенчмарк DiskSpd.

## Файлы

- `index.html` — разметка вкладки;
- `main.js` — клиентская логика (подключается через `core/tab-registry.js`).

## Интеграция

| Параметр | Значение |
|---|---|
| REST API | `/api/storage-manager/{summary,action}` |
| Бэкенд / SDK | `sdk/modules/storage_manager` |
| Загрузка | `/html/tab_storage_manager/index.html` и `/html/tab_storage_manager/main.js` |

Вкладка отражена в интерактивной карте сайта [`tab_sitemap`](../tab_sitemap/README.md).

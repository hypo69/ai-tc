# 🧩 Панель управления Codebase AST & Diagnostic RAG

Модуль клиентского интерфейса субпанели «RAG Кода и Диагностики» во вкладке **Внутренняя архитектура** (`http://localhost:8001/tc#tab-app-internals#codebase-rag`).

---

## 📋 Назначение

Обеспечивает оператора и инженера инструментами взаимодействия с базой знаний об архитектуре и исходном коде проекта:
1. **Диагностика ошибок и логов**: интерактивная подача вопросов, списков логов и текстов ошибок (стек-трейсов) с получением структурированного заключения `CodeDiagnosticConclusion` (первопричина, строки кода, релевантные символы AST, рекомендации по исправлению).
2. **Сборка и управление индексами**: запуск AST-сканирования Python файлов и Markdown-документации с просмотром статистики (число файлов, чанков, символов AST и времени сборки).
3. **Поиск по коду и символам**: поиск функций, методов и классов по именам и сигнатурам, а также гибридный семантический поиск по фрагментам кодовой базы.

---

## 🏛 Архитектура и файлы

- `panel.js` — клиентский модуль контроллера суб-панели (вызовы REST API `/api/rag/codebase/...`, обработка событий, рендеринг заключения).
- `README.md` — данное описание модуля.

---

## 🔗 Интеграция с REST API

- `GET /api/rag/codebase/indexes` — получение перечня активных индексов кодовой базы.
- `POST /api/rag/codebase/build` — сборка или переиндексация целевого каталога проекта.
- `POST /api/rag/codebase/diagnose` — формирование заключения по ошибкам, логам или архитектурным вопросам.
- `POST /api/rag/codebase/symbols` — поиск по реестру AST-символов.
- `POST /api/rag/codebase/search` — гибридный семантический поиск по чанкам кода.

## 📋 Назначение

Вкладка `tab_cloudflared` предоставляет визуальный веб-интерфейс для мониторинга и управления службой Cloudflare Tunnel (`cloudflared`).

## ⚙️ Функциональные возможности

1. **Телеметрия туннеля**: Отображение статуса процесса (PID, потребление CPU и памяти, время непрерывной работы).
2. **Проверка эндпоинта Ingress**: Замер задержки и доступности публичного хоста (`https://kino.davidka.net`).
3. **Журнал событий**: Просмотр последних записей `cloudflared.log` с цветовой индикацией ошибок и предупреждений.
4. **ИИ и эвристическая диагностика**: Оценка надежности туннеля (Health Score 0-100) и практические рекомендации.
5. **Управление службой**: Кнопка немедленного перезапуска туннеля.

## 🔗 Контракты API

- `GET /api/cloudflared/status` — статус туннеля
- `GET /api/cloudflared/logs?limit=50` — хвост журнала
- `GET /api/cloudflared/diagnostic` — отчет о здоровье
- `POST /api/cloudflared/test-endpoint` — HTTP-проверка
- `POST /api/cloudflared/restart` — перезапуск демона

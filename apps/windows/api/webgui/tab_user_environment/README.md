# 🌐 Окружение пользователя (User Environment) — WebGUI

Централизованная вкладка веб-интерфейса AI Windows Admin для комплексного управления пользовательским окружением операционной системы Windows 10/11.

---

## 📌 Архитектура и функционал

Вкладка объединяет в едином пространстве со структурой горизонтальных навигационных пилюль (`nav-pills` с `rounded-pill`) ключевые аспекты окружения:

1. **Панель задач (Taskbar)**:
   - Выравнивание значков панели задач (по центру или по левому краю).
   - Элемент «Поиск» (скрыть, значок, поле поиска, кнопка).
   - Автоматическое скрытие панели задач.
   - Видимость системных элементов: «Виджеты», «Представление задач», «Copilot», бейджи уведомлений.
   - Закрепленные приложения с возможностью мгновенного запуска, открепления и закрепления новых программ.
   - Индикатор прогресса в таскбаре через COM-интерфейс `ITaskbarList3` (Normal, Error, Paused, Marquee).
   - Быстрый перезапуск системного процесса Проводника (`explorer.exe`).

2. **Звук и аудиомикшер (Sound & Mixer)**:
   - Громкость системных звуков Windows (System Sounds) и быстрое заглушение (Mute).
   - Звук запуска Windows (Startup Sound toggle).
   - Тестирование системных сигналов (Asterisk, Exclamation, Beep, Question).
   - Мастер-громкость активного устройства вывода WASAPI и отображение звуковой схемы.
   - Интерактивный микшер громкости активных сессий приложений (Volume Mixer) в реальном времени.
   - Быстрый запуск нативных апплетов звука Windows (`ms-settings:sound`, `sndvol.exe`, `mmsys.cpl`).

3. **Окна рабочего стола (Windows & Desktop)**:
   - Таблица открытых окон рабочего стола с поисковым фильтром по названию, процессу, PID и HWND.
   - Действия над окнами: перевести фокус на передний план, свернуть, развернуть, восстановить, закрыть.
   - Пакетные действия: «Свернуть все окна», «Восстановить все окна».
   - Стандартизированная кнопка Drill-down с красной дрелью (`/html/assets/red_drill.png`) для углубленного ИИ-анализа окна (`AIModalDialog`).

4. **Фокусировка внимания (Focus Assist)**:
   - Сессии фокусировки Windows 11 с настраиваемой длительностью от 5 до 240 минут.
   - Живой таймер обратного отсчета с точностью до секунды.
   - Режим «Не беспокоить» (Do Not Disturb).
   - Подавление мигания значков на панели задач и бейджей уведомлений во время сессии.
   - Интеграция с нативным приложением «Часы» (Windows Clock).

5. **Дисплей и Персонализация (Personalization & Displays)**:
   - Опрос подключенных мониторов и их характеристик (разрешение, частота обновления).
   - Поворот экрана (Альбомная 0°, Портретная 90°, Перевернутые 180° и 270°) с безопасным 15-секундным таймером автовозврата при отсутствии подтверждения.

6. **Журнал изменений SafeOps и мгновенный откат (History & Rollback)**:
   - Аудит всех примененных изменений параметров в локальной базе `telemetry.db`.
   - Гранулярный откат каждого изменения или мгновенный откат последнего действия.

## 🔗 Маршруты интеграции и URL-маршрутизация блоков

- **Веб-путь к разметке:** `/html/tab_user_environment/index.html?v=20261030_v2`
- **Веб-путь к скрипту:** `/html/tab_user_environment/main.js?v=20261030_v2`
- **Идентификаторы контейнера:** `tab-user-environment`, `tab-user-enviroment`
- **Инициализирующая функция:** `window.initUserEnvironmentTab()`, `window.initUserEnviromentTab()`

### Стандарт передачи блоков в URL:
Вкладка строго поддерживает инженерный стандарт маршрутизации блоков через URL hash:
```text
http://localhost:8001/#tab-user-environment#panel-<block_id>
```

Канонические блоки (сегменты URL):
- `#tab-user-environment#panel-taskbar` — Панель задач Windows 10/11
- `#tab-user-environment#panel-sound` — Звук и аудиомикшер WASAPI
- `#tab-user-environment#panel-windows` — Окна рабочего стола
- `#tab-user-environment#panel-focus` — Сессии фокусировки внимания
- `#tab-user-environment#panel-personalization` — Дисплей и Персонализация
- `#tab-user-environment#panel-history` — Журнал SafeOps и откат

Поддерживаются краткие и пользовательские алиасы при вводе в адресную строку (например `#sound`, `#windows`, `#focus`, `#display`, `#safeops`), которые автоматически приводятся к каноническому стандарту.
При переключении между пилюлями интерфейса URL обновляется в режиме реального времени без перезагрузки страницы (`history.replaceState`), а опрос бэкенда выполняется строго по принципу **Active-Only** для активного блока.

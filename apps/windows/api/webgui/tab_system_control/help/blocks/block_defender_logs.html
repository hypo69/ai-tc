4. Раздел «Журналы Defender» (Microsoft Defender Logs)
События антивирусной защиты

Специализированная панель аудита канала Microsoft-Windows-Windows Defender/Operational:

Детекция угроз и вредоносного ПО

События Event 1116 (Угроза обнаружена) и Event 1117 (Действие выполнено): название угрозы, уровень опасности, путь к файлу, процесс-инициатор и результат лечения/помещения в карантин.

Обновления сигнатур и антивирусных баз

События Event 2000: версии установленных баз определений сигнатур, состояние службы ASR (Attack Surface Reduction) и ошибки синхронизации с облаком безопасности Microsoft.

Изменения параметров защиты

Фиксирует факты добавления исключений в сканирование (Exclusions Event 5007), отключение защиты в реальном времени (RTP Event 5001) и смену настроек облачной аналитики.

Аудит сканирований диска

Результаты быстрых, полных и запланированных проверок: время старта, общее время сканирования и количество проверенных файловых объектов.

2. Раздел «Журналы событий» (Event Logs Center)
Дерево каналов и просмотр

Многофункциональный центр инспекции более 1000 каналов Windows Event Log с поддержкой аналитических режимов:

  • Live Events: потоковый просмотр последних записей выбранного канала в реальном времени с поддержкой автообновления (Live-switch).
  • Smart Digest (EDA): интеллектуальная дедупликация и кластеризация повторяющихся сообщений, выделение аномальных всплесков частоты.
  • Семантический RAG-поиск: поиск причин сбоев по естественному языку с использованием векторных эмбеддингов локальной базы знаний.
  • GitHub Activity Heatmap: суточная и почасовая тепловая карта интенсивности ошибок с цветовой индикацией тяжести инцидентов.
Экспорт и сохранение данных: Кнопка «Экспорт» в заголовке позволяет мгновенно выгрузить отфильтрованную выборку событий в форматах JSON или CSV для внешнего расследования или прикрепления к тикетам техподдержки.

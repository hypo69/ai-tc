1. Раздел «Сводка сбоев и аномалий» (Summary Dashboard)
Аварии ядра и стабильность

Оперативная агрегированная панель мониторинга аппаратных и программных сбоев операционной системы:

Дампы BSOD и аварии BugCheck

Отображает количество и расшифровку аварий ядра Windows (синие экраны смерти, LiveKernelReports и стоп-коды BugCheck). Позволяет мгновенно выявить виновный драйвер (.sys), модуль или сбой подсистемы памяти.

Сбои питания (Kernel-Power 41)

Фиксирует внезапные отключения электропитания, принудительные перезагрузки и зависания, при которых система выключилась без предварительного завершения работы (Clean Shutdown).

Троттлинг GPU / CPU и WHEA

Анализирует события аппаратной архитектуры ошибок Windows (WHEA-Logger), термальный троттлинг процессора (PROCHOT) и сбросы видеодрайвера (TDR Event 4101).

Подозрительная активность

Сводка аномальных запусков процессов с повышенными привилегиями, всплесков неудачных входов (Brute-Force) и очистки журналов аудита.

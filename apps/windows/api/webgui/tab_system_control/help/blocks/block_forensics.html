5. Раздел «Форензика» (Поведенческий анализ и артефакты)
Артефакты и таймлайн

Инструменты криминалистического расследования действий пользователей и скрытой активности программ:

Реестр UserAssist (Запуски GUI программ)

Декодирует ROT13-ключи реестра текущего пользователя: точное число запусков каждого приложения, время последнего фокуса и суммарная длительность удержания активного окна.

Аудит сенсоров и оборудования

Хронологический срез сенсорной телеметрии: всплески температуры ядер, просадки напряжений, подключение съемных USB накопителей и сетевых интерфейсов.

Хронологический таймлайн событий

Единая сводка разнородных артефактов (входы в систему, монтирование томов, изменение системного времени и запуск служб), сгруппированная по минутам.

Эскалация привилегий и UAC

Отслеживание диалогов User Account Control, вызовов runas и попыток повышения прав процессами без цифровой подписи.

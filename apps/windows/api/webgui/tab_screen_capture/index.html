Графическая подсистема Windows.Graphics в AI-TC
Семейство Windows.Graphics API предоставляет прямой доступ к графической подсистеме Windows без использования устаревших GDI-битмапов, с поддержкой нулевого копирования на GPU (Zero-Copy) и передачи кадров через Direct3D 11.

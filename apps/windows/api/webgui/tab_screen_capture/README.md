# 🖥️ Вкладка WebGUI: Windows.Graphics.Capture & Screen Capture

Модуль веб-интерфейса для интерактивного управления экранным захватом, мониторинга дисплеев и окон, настройки графических параметров и корреляции с ETW-телеметрией ядра Windows.

---

## 📋 Возможности

1. **Монитор захвата (Live Stream & Snapshots)**:
   - Выбор между захватом физических/виртуальных мониторов и конкретных окон приложений.
   - Быстрый фильтр окон по заголовку и имени процесса.
   - Моментальный снимок экрана с отображением в реальном масштабе.
   - Запуск фонового видеопотока с индикацией фактического FPS.
   - Мини-галерея недавних снимков.

2. **Панель настроек захвата (Settings)**:
   - Выбор графического бэкенда (`auto`, `wgc`, `gdi`).
   - Лимит частоты кадров (1..30 FPS).
   - Формат сжатия (JPEG, PNG) и качество компрессии.
   - Порог чувствительности Screen Diff (в процентах).
   - Включение/отключение сопоставления снимков с системной ETW-телеметрией.

3. **Корреляция с ETW телеметрией**:
   - Таблица событий, связывающая снимок экрана со значениями CPU, памяти, диска и инцидентами ядра.
   - Детекция зависших окон (`IsHungAppWindow`) и статического экрана при высокой загрузке.

4. **Анализ графической подсистемы**:
   - Диагностика пространств имён Windows.Graphics (Capture, DirectX, Imaging, Display, Effects).

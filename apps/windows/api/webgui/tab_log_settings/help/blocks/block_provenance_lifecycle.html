5. Подразделы «Граф процессов (Provenance)» и «Жизненный цикл ОС»
panel-log-settings-9 / 10
Граф происхождения процессов (Process Provenance)

Реконструирует полную причинно-следственную цепочку запуска: User → Process → Parent Process → Service → Scheduled Task на основе собранных событий Event 4688 за последние 72 часа.

Введите имя исполняемого файла (например, powershell.exe или python.exe) и нажмите «Построить граф», чтобы увидеть родительский процесс, PID, учетную запись инициатора и полную командную строку.
Жизненный цикл ОС (Boot / Sleep / Crash)

Выстраивает единую хронологическую ленту (Timeline) переходов состояния питания и ядра системы: BOOT → LOGIN → SLEEP → WAKE → SHUTDOWN / CRASH.

Позволяет выбрать горизонт анализа (24 часа, 3 дня, 7 дней, 30 дней) и мгновенно выявить нештатные перезагрузки (Kernel-Power 41), сбои питания и стоп-ошибки BSOD.

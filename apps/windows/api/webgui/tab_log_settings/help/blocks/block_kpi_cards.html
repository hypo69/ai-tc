1. Верхние сводные карточки состояния (KPI)
Обзор в реальном времени

Четыре верхних виджета отображают оперативную телеметрию подсистемы логирования Windows Event Log и фонового сборщика событий безопасности (обновление каждые 20 секунд при активной вкладке):

Журнал Security (EVTX) panel-log-settings-1

Показывает текущий физический размер файла Security.evtx и установленный максимальный лимит (в МБ), прогресс-бар заполнения, общее число записей и статус активности канала. При заполнении выше 90% индикатор предупреждает о риске перезаписи старых событий (FIFO).

Аудит CommandLine (Event 4688) panel-log-settings-2

Отображает состояние системной политики включения полной командной строки (ProcessCreationIncludeCmdLine_Enabled) в события создания процессов Event ID 4688. Кнопка «Переключить политику» мгновенно активирует или отключает запись аргументов запуска в реестре.

Сборщик Telemetry.db и Закладка panel-log-settings-3

Контролирует инкрементальный сборщик событий в локальную базу telemetry.db: показывает число сохраненных событий, последний обработанный Record ID (Bookmark) и время синхронизации. Позволяет запустить сбор вручную или сбросить закладку в конец журнала.

Иерархия 7 доменов и Sysmon panel-log-settings-4

Проверяет наличие и статус драйвера/службы Sysmon (System Monitor), суммирует общее количество записей по всем 7 доменам телеметрии ОС и предоставляет кнопку принудительного обновления всех панелей.

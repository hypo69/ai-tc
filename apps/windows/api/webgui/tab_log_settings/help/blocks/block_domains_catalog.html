2. Подраздел «7 Доменов и Каталог провайдеров»
panel-log-settings-5

Структурирует сотни каналов Windows Event Log в 7 логических доменов телеметрии и дополнительный контур глубокой наблюдаемости Sysmon:

  • 1 Security / Identity: входы (4624/4625), привилегии, управление учетными записями.
  • 2 Process / Tasks: жизненный цикл процессов (4688/4689), задания планировщика, службы.
  • 3 Storage & Filesystem: NTFS, Disk, StorPort, VSS теневые копии и ошибки блочного ввода-вывода.
  • 4 Network & Sockets: DNS-клиент, брандмауэр WFP, SMB, TCP/IP соединения и адаптеры.
  • 5 Windows Update: установка патчей KB, Servicing, состояния перезагрузки и откаты.
  • 6 Hardware / Drivers: Kernel-PnP, загрузка драйверов, WHEA аппаратные сбои и USB.
  • 7 Power / Boot / Shutdown: Kernel-Power (41, 107), переходы в сон, гибернацию и BSOD BugCheck.
  • + Sysmon Observability: хэши образов, сетевые коннекты, инъекции памяти и DNS-запросы.
Как работать с таблицей каталога провайдеров: Клик по любой карточке домена автоматически фильтрует таблицу «Иерархический каталог провайдеров Windows». Для каждого провайдера указаны ключевые Event ID (с всплывающими расшифровками), рейтинг объема трафика (Low / Medium / High / Extreme), рекомендуемый метод сбора (ETW Stream или Pull) и теги корреляции.

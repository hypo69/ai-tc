6. Подраздел «Инспектор событий» (Master-Detail)
panel-log-settings-11

Двухпанельный инструмент оперативного расследования инцидентов, позволяющий напрямую опрашивать живые каналы Security, System, Application, Sysmon, TaskScheduler, а также нормализованное хранилище telemetry.db:

Панель быстрых фильтров и поиска:
  • Кнопки Event ID: мгновенная фильтрация по самым востребованным кодам безопасности: 4688 (Создание процесса), 4624 (Успешный вход Logon), 4625 (Неудачный вход / Brute-force), 1102 (Очистка журнала аудита).
  • Многокритериальный фильтр: отбор по уровню критичности (Critical, Error, Warning, Information), имени пользователя, процессу и подстроке в тексте сообщения.
Правая карточка детального разбора:

При клике на любую строку таблицы в правой панели автоматически раскрывается карточка события: точная метка времени, целевой/субъектный пользователь, процесс с PID, выделенный блок CommandLine, родительский процесс и спойлер «Показать исходные данные (Raw Data)» с полной JSON-структурой записи.

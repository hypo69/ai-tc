Политики аудита и привилегии (Левая панель)

Управляет параметром реестра HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System\Audit\ProcessCreationIncludeCmdLine_Enabled. Включение этой политики критически важно для работы графа процессов (Provenance) и ИИ-анализатора, так как без неё Windows скрывает переданные аргументы запуска программ.

Нижний индикатор проверяет наличие привилегии SeSecurityPrivilege у процесса сервера для беспрепятственного чтения защищенного канала Security.

Инкрементальный сборщик и Bookmark (Правая панель)

Чтобы не перечитывать гигабайты старых логов при каждом опросе, сборщик хранит указатель (Bookmark RecordID) в базе telemetry.db:

  • Установить закладку: введите конкретный Record ID или оставьте поле пустым для мгновенного перехода в конец журнала (пропуск архивных записей).
  • Ручной запуск сбора: выберите размер пакета (100, 500, 1000 или 5000 событий) и нажмите «Запустить сбор» для немедленной инжекции свежих событий в SQLite.

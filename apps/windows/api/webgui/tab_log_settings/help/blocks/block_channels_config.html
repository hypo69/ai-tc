3. Подраздел «Параметры и размеры каналов»
panel-log-settings-6

Табличный менеджер всех каналов Windows Event Log позволяет контролировать квоты дискового пространства, диапазоны записей (Oldest..Newest Record ID) и политики ротации без вызова системной оснастки eventvwr.msc:

Настройка канала (Кнопка шестеренки)
  • Максимальный размер (Max Size): ручной ввод в МБ или быстрые пресеты (20 MB, 64 MB, 128 MB, 256 MB, 512 MB, 1 GB, 2 GB).
  • Включить сбор (Enabled): активация/остановка записи в канал (аналог wevtutil sl /e:true).
  • Автоархивация (AutoBackup): автоматическое сохранение переполненного журнала в архивный файл .evtx.
  • Политика удержания (Retention): блокировка перезаписи старых событий (по умолчанию используется кольцевой буфер FIFO).
Безопасная очистка с резервной копией

Кнопка корзины открывает диалог очистки выбранного журнала. По умолчанию включена опция «Создать резервную копию (.evtx) перед очисткой» с автоматической генерацией пути вида C:\Windows\Temp\evtx_backup_<Channel>_<Timestamp>.evtx.

При очистке канала Security система автоматически генерирует аудиторское событие Event ID 1102.

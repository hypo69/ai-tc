6. Досье инстанса (Process Intelligence Deep Dive) и SafeOps управление
7 виджетов и SafeOps

Модальное окно углубленного анализа инстанса процесса (открывается кликом по строке или иконке Drill-Down 🔬):

Виджет 1: Профиль инстанса (Instance Profile)

Точный PID, Creation Time, хеш исполняемого файла, пользователь-владелец (User SID), статус цифровой подписи Authenticode и полная командная строка запуска CommandLine.

Виджет 2: Действия SafeOps

Безопасное управление: смена класса приоритета (Realtime, High, Normal, Idle), маска привязки ядер (CPU Affinity), заморозка/возобновление потоков (Suspend/Resume) и грациозное/принудительное завершение.

Виджет 3: 4 Синхронизированных графика Chart.js

Динамические временные ряды с единой осью времени: утилизация % CPU, Private Bytes RAM (утечки памяти), дисковый I/O (Read/Write КБ/с) и дескрипторы Handles.

Виджет 4: Иерархия Lineage

Древовидная родословная процесса: кто родитель (Parent Process -> Explorer/Services/TaskScheduler), каков PPID и какие дочерние подпроцессы уже порождены.

Виджет 5: Дескрипторы ОС, GDI и USER

Аудит Handle Leaks: открытые файловые дескрипторы, ключи реестра, мьютексы, а также оконные объекты GDI/USER с контролем системного лимита.

Виджеты 6 и 7: Сокеты и Лента файлов

Сетевые соединения процесса (TCP/UDP, удаленный IP, порт, состояние) и журнал недавних файловых операций ввода-вывода (Read/Write/Delete).

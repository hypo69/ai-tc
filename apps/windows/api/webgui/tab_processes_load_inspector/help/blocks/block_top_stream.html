2. Топ процессов хоста (Live Stream)
Потоковый мониторинг

Высокочастотный мониторинг самых активных потребителей системных ресурсов в реальном времени:

Метрики нагрузки (CPU, RAM, Disk, IOPS)

Отображает % использования процессора, приватный рабочий набор (Working Set), скорость чтения/записи на диск и частоту операций ввода-вывода (IOPS).

Иконка Drill-Down перехода

Клик по иконке бинокля в строке процесса мгновенно открывает модальное окно глубокого анализа Process Intelligence Deep Dive для конкретного PID.

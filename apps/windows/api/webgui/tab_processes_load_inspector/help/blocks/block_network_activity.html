Сетевой мониторинг

Инспекция сетевого трафика каждого запущенного процесса через Windows IP Helper API:

Активные соединения (TCP / UDP)

Отображает локальный IP/порт, удаленный узел, доменное имя, статус сокета (ESTABLISHED, LISTENING, TIME_WAIT) и привязанный процесс.

Скорость отправки и приема

Замеряет входящий и исходящий трафик (КБ/с и МБ/с) в реальном времени, помогая выявить фоновые загрузки, утечки данных и подозрительные сетевые коннекты.

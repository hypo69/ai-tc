4. Изменения файлов в реальном времени (ReadDirectoryChangesW)
Файловый трекинг

Низкоуровневый перехват модификаций файловой системы через системный API ядра Windows:

Типы событий (Created, Modified, Renamed, Deleted)

Отображает непрерывную ленту операций создания, перезаписи, переименования и удаления файлов на отслеживаемых дисках и каталогах.

Привязка к процессам-инициаторам

Коррелирует файловые операции с дескрипторами открытых файлов активных процессов, позволяя точно установить, какая программа изменила файл.

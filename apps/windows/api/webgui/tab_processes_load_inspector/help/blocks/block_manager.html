1. Диспетчер процессов и приложений (Process Manager)
Диспетчер задач

Иерархический диспетчер задач Windows с группировкой процессов по категориям, подпроцессам и окнам приложений:

Приложения (Apps) и Фоновые процессы

Разделяет пользовательские оконные программы (с отображением заголовков окон), фоновые службы и системные процессы Windows. Поддерживает раскрытие дерева дочерних процессов.

PID Recycling Guard

Защита от переиспользования идентификаторов PID операционной системой: предотвращает отправку команд управления не тому процессу, сверяя время запуска (Creation Time).

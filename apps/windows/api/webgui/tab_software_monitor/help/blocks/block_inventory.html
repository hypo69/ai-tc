1. Реестр программ (Инвентарь ПО)
Полный реестр

Централизованная таблица инвентаризации установленного программного обеспечения всех архитектур (x64, x86/WoW6432Node и пакетов MSIX/AppX):

Источники обнаружения ПО

Опрашивает ключи деинсталляции HKLM/HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall, пакетные манифесты AppX, каталоги Program Files и базу MSI.

Тихая деинсталляция (Quiet Uninstall)

Позволяет запускать удаление программ с ключами тихого режима (/qn, /silent, /verysilent) без всплывающих диалоговых окон установщиков.

Спящие программы (>90 дней без запуска)

Определяет редко запускаемое ПО, занимающее дисковое пространство и системные ресурсы. Сравнивает дату установки с последней меткой времени выполнения в файлах C:\Windows\Prefetch\*.pf.

Сироты и остатки деинсталляции (Orphans)

Поиск брошенных служб, задач планировщика, отсутствующих исполняемых файлов в реестре автозапуска и неудаленных каталогов в AppData\Roaming и AppData\Local.

4. Автозапуск программ (Startup Auditor)
Оптимизация загрузки

Аудит всех точек входа автозапуска Windows, влияющих на время старта системы и фоновую нагрузку:

Точки автозагрузки (Registry & Startup Folders)

Сканирует ветви реестра Run, RunOnce, RunServices, папки Shell:Startup и Common Startup, а также системные триггеры Windows Logon.

Влияние на загрузку (Startup Impact)

Оценивает степень задержки загрузки рабочего стола (High / Medium / Low) и предоставляет мгновенное переключение (Enable / Disable) элементов без удаления записей.

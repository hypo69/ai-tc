# 🛡️ Digital Forensics & Incident Response (Цифровая криминалистика и расследование инцидентов)

Полнофункциональная подсистема цифровой криминалистики (Digital Forensics) и доказательного расследования инцидентов для операционной системы Windows в составе **ai-tc**.

---

## 🏛️ Трехуровневая архитектура цифровой форензики

```
┌─────────────────────────────────────────────────────────────┐
│ 3. Intelligence Layer (Интеллектуальное исследование)       │
│    • Incident Reconstruction Engine (Сценарии расследования)│
│    • Анализ сбоев, перезагрузок (Root Cause Analysis)       │
│    • Детекция аномалий процессов и связей с USB             │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 2. Forensic Analysis Layer (Анализ и доказательства)        │
│    • Unified Chronological Super-Timeline                   │
│    • Корреляция событий (Event Correlation)                 │
│    • Юридическая цепочка сохранности (Chain of Custody)     │
│    • Криптографическая неизменность: SHA-256 Hashing        │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 1. Acquisition Layer (Сбор цифровых доказательств)          │
│    • Prefetch (.pf с нативной MAM-распаковкой)              │
│    • UserAssist (ROT13 декодирование реестра)               │
│    • Аппаратные следы USB (HKLM\...\USBSTOR)                │
│    • Журналы событий ОС (System.evtx, Security.evtx)        │
│    • Аудиосессии процессов в реальном времени (WASAPI)      │
└─────────────────────────────────────────────────────────────┘
```

## 📋 Основные возможности

1. **Реконструкция инцидентов (Incident AI)**:
   - Автоматическое расследование внезапных выключений, сбоев питания (Kernel-Power 41/6008) и системных дампов (BSOD BugCheck 1001).
   - Расследование подключений съемных USB-накопителей с идентификацией аппаратных серийных номеров.
   - Построение картины событий в заданном временном окне ($\pm N$ минут) с формулировкой первопричины (Root Cause) и оценкой достоверности выводов (Confidence Score).

2. **Единый супер-таймлайн (Super-Timeline)**:
   - Сквозная нормализация времени в UTC ISO-8601 для всех типов событий: запуск ПО, подключение накопителей, системные события ядра, сетевые сокеты и аудиопотоки.

3. **Артефакты исполнения программ (Execution Artifacts)**:
   - Распаковка и анализ файлов `C:\Windows\Prefetch\*.pf` (MAM XPRESS-Huffman decompress через `RtlDecompressBufferEx`).
   - Анализ истории запусков и фокусного времени `UserAssist` из реестра Windows.

4. **Аппаратные доказательства (USBSTOR)**:
   - Извлечение данных из ветки `SYSTEM\CurrentControlSet\Enum\USBSTOR`: производитель (Vendor), модель (Product), уникальный серийный номер (S/N), ревизия прошивки и идентификатор устройства.

5. **Жизненный цикл ОС и аутентификация**:
   - Корреляция плановых перезапусков (1074 User32), аварийных отключений (41/6008), установки новых служб/драйверов (7045 SCM) и входов пользователей (4624/4625).

6. **Цепочка сохранности доказательств (Chain of Custody)**:
   - Каждое доказательство криптографически заверяется контрольной суммой SHA-256 с фиксацией времени сбора и модуля фиксации.

7. **Оперативная телеметрия и звук (WASAPI Live)**:
   - Отображение активного окна в фокусе, времени простоя пользователя и приложений, использующих аудиовывод (наушники/колонки) и микрофон в данный момент.

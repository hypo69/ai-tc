# Вкладка "Защита ядра и драйверы Windows" (`tab_kernel_protection`)

**Updated:** 2026-11-01 14:40:00

## 📋 Описание вкладки

Интерактивная консоль диагностики и управления подсистемой **Windows System Protection & Enforcement** в WebGUI AI Windows Admin.

Вкладка предназначена для системных инженеров и администраторов, позволяя детально анализировать системные фильтры, драйверы ядра, механизмы защиты и расследовать точные причины системных блокировок и отказов в доступе (Access Denied).

---

## 🎛️ Панели управления

1. **Механизмы защиты ядра**:
   - Индикация статусов: HVCI / Memory Integrity, Secure Boot, UCPD, Defender Tamper Protection, Smart App Control, Driver Blocklist, UAC / luafv, Code Integrity.
   - Детальное описание влияния каждого механизма на конфигурирование Windows.
2. **Системные драйверы (Инвентарь)**:
   - Интерактивный поиск и фильтрация по категориям (Все, Защитные, Минифильтры, Системные, Сторонние).
   - Интеграция с `window.AIModalDialog.show()`: контекстный AI-анализ каждого .sys-драйвера, его критичности и роли в защите.
3. **Файловые минифильтры (fltmc)**:
   - Таблица активных минифильтров файлового ввода-вывода (IRP), номеров высот (Altitudes) и групп Microsoft Altitude Groups.
4. **Диагностика блокировок (Operation Blocker Detection)**:
   - Стенд расследования отказов в доступе.
   - Быстрые пресеты для проверки `UserChoice` (UCPD), `TaskbarDa`, `Windows Defender` (Tamper Protection) и системных файлов.
   - Пошаговое тестирование цепочки: UAC токен -> UCPD -> Tamper Protection -> ACL дескриптор -> GPO/MDM -> журналы событий.
   - Итоговый вердикт с расчетом уверенности и безопасными рекомендациями.
5. **Безопасное управление (SafeOps)**:
   - Контролируемое временное отключение и включение драйвера UCPD с созданием точек отката.
   - Защита от случайного отключения критических компонентов ядра (BSOD prevention).

---

## 📡 Контракты API

- `GET /api/kernel-protection/summary` — Сводка механизмов и драйверов.
- `GET /api/kernel-protection/drivers` — Список системных драйверов с фильтрацией.
- `GET /api/kernel-protection/minifilters` — Таблица минифильтров `fltmc`.
- `POST /api/kernel-protection/investigate-blocker` — Расследование блокировки.
- `POST /api/kernel-protection/safe-action` — Безопасное управление.

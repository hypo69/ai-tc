## Описание
Автономный навык реализации задач по спецификациям GitHub Issues. Превращает задачи в репозитории в структурированные ТЗ, автоматически создает ветки `fix/...` и `feat/...`, запускает проверочные тесты и формирует Pull Request со связкой `Fixes #...`.

- `scripts/issue_to_pr_runner.py` — консольный оркестратор рабочего цикла разработки.
- `references/ai_task_workflow.md` — описание сквозного 9-шагового процесса разработки.
